# AstraZit Brand Skill

## 1. Purpose
This skill establishes guidelines for maintaining consistency across visual artwork, typography, copy tone, visual overlays for broadcasts, and metadata presentation for the AstraZit project.

## 2. Activation Context
Activate this skill when:
- Designing or reviewing visual assets (album art, stream overlays, promotional cards).
- Formatting public-facing artist bios, track descriptions, and liner notes.
- Defining UI themes for AstraZit applications (`apps/radio`, `apps/website`, `apps/admin`).
- Reviewing typography and color schemes across derivative media.

## 3. Constraints
- **Consistency**: Visual assets must adhere strictly to established AstraZit brand tokens once ratified.
- **No Arbitrary Design Inventions**: Do not fabricate unauthorized brand lore, official color palettes, or assets before formal brand documentation is authored.
- **Human Review**: Public artist statements, release descriptions, and visual re-brands require human approval.
