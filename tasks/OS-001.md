# Task OS-001: Repository Foundation & Core Governance

## Summary
Establish the repository structure, cross-platform Git configurations, environment templates, foundational documentation, and architectural decision records for **AstraZit Music OS**.

## Status
- **State**: In Progress / Verification
- **Assignee**: Antigravity Agent
- **Parent Ticket**: None (Initial Repository Setup)

---

## Scope & Deliverables
1. **Core Documentation**:
   - `PROJECT.md`: Project mission, 4-tier philosophy (Database/Code/AI/Human), relationship to AstraZit Radio, canonical data and immutable identity principles, Phase 0 non-goals.
   - `DECISIONS.md`: Initial ADRs (ADR-001 through ADR-008).
2. **Git & Environment Configuration**:
   - `.gitattributes`: LF line endings for Linux/POSIX runtime and documentation; CRLF allowed for Windows scripts.
   - `.gitignore`: Robust ignore rules covering secrets, local audio masters, Python venvs, node_modules, logs, and OS files.
   - `.env.example`: Sanitized environment template without real credentials.
3. **Directory Skeleton**:
   - Establishment of core directories (`docs/`, `catalog/`, `apps/`, `services/`, `packages/`, `infrastructure/`, `scripts/`, `tests/`, `tasks/`, `reports/`).

---

## Acceptance Criteria
- [x] Repository root contains `PROJECT.md`, `DECISIONS.md`, `.gitattributes`, `.gitignore`, and `.env.example`.
- [x] All listed directories exist with `.gitkeep` placeholders for empty folders.
- [x] `.gitattributes` normalizes text to LF by default and specifies LF for `.sh`, `.liq`, `.service`, `.conf`, `.py`, `.json`, `.yaml`, `.yml`, `.md`.
- [x] `.gitignore` prevents tracking of `.env`, `*.key`, `*.pem`, service account JSONs, audio libraries (`*.wav`, `*.flac`, etc.), and runtime logs.
- [x] No Google Cloud resources were created, modified, or deleted.
- [x] No commits or remote pushes executed.
