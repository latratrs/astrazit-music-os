## Background & Context
Following ADR-012, AstraZit Music OS catalog entities are partitioned into three immutable namespaces: Musical Work (`AST-WRK-`), Sound Recording (`AST-REC-`), and Release (`AST-REL-`). Ticket OS-004 implements the deterministic mechanism for issuing these identifiers in strict monotonic order across independent namespaces without coupling to external platform adapters.

## Technical Approach & Architecture Constraints
- **Independent Namespaces**: Counters advance independently without a shared global sequence.
- **Fail-Closed Durability**: Any state file corruption, schema violation, or persistence error aborts immediately without automatic reset.
- **Concurrency Boundary**: Guarantees zero duplicate allocations across concurrent threads and local processes on a single host. Does not claim distributed multi-host safety.
- **External Identifier Decoupling**: External codes (ISRC, ISWC, UPC, DSP IDs) remain adapters and never influence internal ID allocation.

## Acceptance Criteria
- [x] AC-1: First allocations issue `AST-WRK-000001`, `AST-REC-000001`, `AST-REL-000001`.
- [x] AC-2: Allocation sequence is monotonic (`000001`, `000002`, `000003`).
- [x] AC-3: Namespaces operate completely independently.
- [x] AC-4: State survives process restart across store instances.
- [x] AC-5: Invalid entity types fail without mutating sequence state.
- [x] AC-6: Counter at `999999` fails closed with `SequenceExhaustedError`; other namespaces continue.
- [x] AC-7: Corrupted or malformed state fails closed with `SequenceStateError`; zero auto-repair.
- [x] AC-8: Threaded and multi-process concurrent allocations produce strictly unique, monotonic IDs.
- [x] AC-9: Pre-replace write failure retains existing canonical state; post-replace failure may burn a sequence without rolling back. Failed first initialization may require recovery.
- [x] AC-10: CWD-independent and relocated checkout execution pass cleanly.
- [x] AC-11: Zero regression of OS-003 schemas and test suite.
- [x] AC-12: Zero secrets, real tokens, or production IDs present.
