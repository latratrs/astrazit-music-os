### 2. Real SDK Static & Runtime API Verification
- **Client**: `google.cloud.firestore.Client` supports explicit collection and transaction instantiation (`client.collection(...)`, `client.transaction(max_attempts=...)`). Note: `Client.run_transaction` does not exist on the Python Client class (which provides `client.transaction()` and the `@firestore.transactional` decorator).
- **Transaction Class**: `google.cloud.firestore_v1.transaction.Transaction`.
  - Transaction reads: `doc_ref.get(transaction=txn)` and `txn.get(doc_ref)` return document snapshots.
  - Transaction updates: `transaction.update(doc_ref, updates)` buffers write mutations. Note: calling `doc_ref.update(updates, transaction=txn)` is rejected by the SDK (`TypeError: got unexpected keyword argument 'transaction'`).
  - Transaction creations: `transaction.create(doc_ref, data)` buffers create mutations with `exists: false` preconditions.
- **Server Timestamps**: `firestore.SERVER_TIMESTAMP` correctly serializes into transform mutations (`REQUEST_TIME`) in both `create` and `update` write protobufs.
- **Transaction Decorator & Retries**: `firestore.transactional` decorates callables and executes an internal retry loop (`max_attempts`, defaulting to 5) catching `google.api_core.exceptions.Aborted`. If all attempts fail, it raises `ValueError("Failed to commit transaction in X attempts.")` with the underlying `Aborted` exception chained as `__cause__`.
- **Error Mapping**:
  - `google.api_core.exceptions.AlreadyExists` / `Conflict` -> mapped to `SequenceStoreConflictError`.
  - Exhausted transaction contention (`ValueError` with `Aborted` cause) -> mapped to `SequenceStoreConflictError`.

### 3. Real Local Firestore Emulator Status
- **Status**: `REAL FIRESTORE EMULATOR NOT TESTED`
- **Root Cause & Reason**: The official Google Cloud Firestore emulator jar (`cloud-firestore-emulator-v1.20.2.jar`) downloaded by Firebase CLI requires Java Runtime class file version 65.0 (Java 21+), whereas the host machine environment provides Java SE 14.0.1 (`java.lang.UnsupportedClassVersionError: com/google/cloud/datastore/emulator/firestore/CloudFirestore has been compiled by a more recent version of the Java Runtime (class file version 65.0)`).
- **Integration Test Suite**: Created `tests/integration/test_firestore_emulator_sequence_store.py` with explicit fail-safe gating:
  - Requires explicit `FIRESTORE_EMULATOR_HOST` environment variable.
  - Safely and cleanly skips if `FIRESTORE_EMULATOR_HOST` is absent (`OK (skipped=1)`).
  - Explicitly uses `AnonymousCredentials()` to ensure zero production cloud connection under any circumstances.
  - Implements bootstrap, concurrency, monotonicity, and ledger immutability tests ready for CI/CD environments with Java 21+ and the emulator running.

### 4. Implementation Enhancements in OS-006A
- In `packages/catalog/firestore_sequence_store.py`:

  - Mapped Firestore concurrency errors (`Aborted`, `AlreadyExists`, `Conflict`) into `SequenceStoreConflictError`.
