# OS-008 — Local Admin Catalog Viewer

## 1. Overview
- **Ticket**: OS-008
- **Base Commit**: 28a24c5
- **Scope**: Local, read-only browser-based catalog viewer built on top of the OS-007 demo sandbox and OS-005 `LocalJsonCatalogRepository`.
- **Governing ADRs**: ADR-001, ADR-003, ADR-012, ADR-014, ADR-015, ADR-016.

---

## 2. Acceptance Criteria & Implementation Results
- [x] Standard library Python web stack (zero external runtime dependencies).
- [x] Bound to loopback `127.0.0.1` by default (port 8765).
- [x] Read-only contract enforced: no mutation routes, all write verbs return 405 Method Not Allowed.
- [x] URL contract fulfilled:
  - `GET /` -> Redirects to `/admin/catalog`
  - `GET /health`
  - `GET /admin/catalog`
  - `GET /admin/catalog/works`
  - `GET /admin/catalog/works/<demo_id>`
  - `GET /admin/catalog/recordings`
  - `GET /admin/catalog/recordings/<demo_id>`
  - `GET /admin/catalog/releases`
  - `GET /admin/catalog/releases/<demo_id>`
- [x] Demo identity safety: internal AST fixture IDs (`AST-WRK-*`, `AST-REC-*`, `AST-REL-*`) do not leak into rendered HTML.
- [x] AST-shaped URL paths are cleanly rejected with 404.
- [x] Zero production allocator calls (`IdentifierAllocator`, `LocalJsonSequenceStore`, `FirestoreSequenceStore` never instantiated).
- [x] Zero cloud / Firestore / network access.
- [x] Missing or corrupted sandbox returns informative local error response (503 / 500) without leaking stack traces or absolute paths.
- [x] Comprehensive automated test suite in `tests/test_catalog_viewer.py` passes completely.
- [x] Full regression suite (schemas, audit, id_service, catalog_repo, firestore_store, catalog_demo) passes.
