# Task OS-010: Historical Catalog Intake Staging and WAV QC

## Summary

Prepare the 139-song historical AstraZit CSV and explicitly mapped WAV masters for
human review without creating canonical catalog records. The implementation produces
a deterministic local staging manifest, keeps analyzed metadata provisional, records
read-only source-audio QC, and separates master validity from radio-derivative need.

## Scope & Deliverables

- [x] Strict deterministic parser for the eight-column historical CSV.
- [x] Source SHA-256 and source-row provenance without identity derivation.
- [x] Duplicate-title review flags without automatic merges.
- [x] Provisional six-daypart mapping and representative metadata candidates.
- [x] Rotation inputs preserved without assigning tiers.
- [x] Explicit WAV row map; zero filename guessing.
- [x] Read-only WAV PCM, hash, duration, peak, clipping, and optional loudness QC.

  YouTube, stream keys, VISUAL-003, OS-009, and RADIO-006.

## Architecture Constraints

- Source hashes and row numbers provide audit locators only; they never produce IDs.
- Genre/daypart data remains provisional until human promotion.
- WAV maps use explicit CSV source rows so duplicate song titles remain distinct.
- Missing full loudness analysis fails incomplete, never as a guessed pass.
- All staging output defaults beneath ignored `.local/catalog/` state.

## Human Approval Requirements

- GATE-06 is not exercised: OS-010 records rights as not supplied and performs no
  ownership or clearance mutation.
- A later canonical import requires explicit human approval for rights-bearing data
  and production identifier authority.

## Acceptance Criteria

- [x] No call path imports or invokes an allocator, sequence store, or repository.
- [x] Every staged record has null AST IDs and `ready_for_radio=false`.
- [x] Original WAV SHA-256 remains unchanged after inspection.
- [x] Same input produces byte-identical manifest JSON.
- [x] Unknown columns, dates, values, dayparts, or WAV mappings fail closed.
- [x] Targeted and existing catalog regression tests pass.
